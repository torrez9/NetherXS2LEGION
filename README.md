## 📥 Instalación

1. Descarga el archivo APK desde la [sección de Releases](https://github.com/torrez9/NetherXS2LEGION/releases).
2. Habilita la instalación desde orígenes desconocidos en tu dispositivo Android.
3. Instala el APK y abre la aplicación.
4. Coloca tus BIOS de PS2 (si es necesario) y ¡disfruta!

> **Nota:** Este emulador no incluye BIOS ni juegos; debes proporcionarlos legalmente.

## 🛠️ Construido con
